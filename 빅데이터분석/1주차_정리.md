## PART 1 — Python 기초와 함수형 프로그래밍
- Python 2→3 차이: `print()`, `3/2 → 1.5`, 유니코드 기본
- 가상환경: 프로젝트별 독립 site-packages, 버전 고정 → 재현성. 윈도우 `py -3.9 -m venv env3.9`, `env3.9\Scripts\activate`
- **sys.path 3단계 규칙**: ① `sys.modules` 캐시 확인 → ② `sys.path` 순서 탐색 (표준 라이브러리 → 가상환경 → site-packages) → ③ 로드·등록. 수정한 라이브러리는 `importlib.reload(sys.modules['myLib'])`
- 변수 = 이름 붙은 상자, 동적 타이핑. `7*3. → 21.0` (큰 쪽 결과). `+`, `*` 오버로딩
- for(정해진 횟수, range) / while(조건, 종료 조건 없으면 무한루프) / if-elif-else(배타적 분기)
- 컨테이너: tuple `()` 불변, list `[]` 가변, set `{}` 중복 불가, dict `{키:값}` 키 유일
  - `myList[2:4]`, `myList[::2]`, 음수 인덱스
  - 없는 키 → KeyError → `defaultdict(int)` 또는 `setdefault()`
- 함수 `def` vs `lambda`(무명, 한 줄, return 없이 반환). 출력 형식 3종: `%`, `.format()`, f-string
- 재귀: 종료 조건 필수, n을 줄이며 자기 호출, 값은 return으로 돌려줘야 함. 이진탐색은 `mid±1`로 범위 좁혀야 무한루프 방지
- 스크립트: `%%writefile`, `%run`, `!python`, `sys.argv[1]`. 내 라이브러리 = 함수 담은 .py를 import
- **map · filter · reduce** — for문을 없애는 연산의 추상화
  - `map(fn, data)` 변환(개수 유지), `filter(fn, data)` 선별(True만), `reduce(fn, data)` 두 값씩 접어 하나로
  - `reduce(lambda x, y: x+y, range(1,101)) → 5050`
  - 문자열에 바로 map하면 철자 단위 → 문장 리스트에 map해야 `split()`으로 단어 단위
  - 요소별 처리가 독립 → 분산 가능 → Spark/Hadoop map-reduce와 같은 사고방식

## PART 2 — NumPy 배열과 선형대수
- 벡터화(SIMD): 반복문 없이 배열 전체를 한 번에. Pandas·scikit-learn·PyTorch 모두 NumPy 위에
- 생성: `np.array`, `np.arange(10)`, `np.zeros/ones((2,3))`, `np.linspace(0,10,num=5)`, `np.eye(4)`
- 속성: `shape`(3,)는 1차원 3요소, `ndim`, `size`, `dtype`(i4, f8)
- **axis**: 0 = 행을 따라 연산 → 결과가 열별, 1 = 열을 따라 → 행별. insert/delete/concatenate도 같은 규칙
- 집계: sum/prod/mean/std/var/max/min/argmax/argmin/np.unique/np.sort
- 재구조: `reshape`, `flatten`, `vstack/hstack`, `np.r_/np.c_`, `a[np.newaxis,:]` (1,3) / `a[:,np.newaxis]` (3,1)
- 인덱싱: `x[:, :-1]`, 논리 인덱싱 `x[x%2==0]` → 1차원 반환. 배열은 mutable, delete/concatenate는 새 배열 반환
- 복사: `y = x` 얕은 복사(주소 공유), `z = x.copy()` 깊은 복사
- **브로드캐스팅 3규칙**: ① 뒤쪽 차원부터 비교 ② 차원 수 적으면 왼쪽에 1 ③ 1인 축만 확장, 아니면 ValueError
  - (4,3)+(3,) → OK, (3,)+(2,1) → (2,3), (4,3)+(2,) → ValueError
- `*` = 요소별 곱 (같은 위치끼리), `np.dot` / `@` = 행렬곱 (행×열, 안쪽 차원 같아야). `np.matrix`는 레거시, `ndarray + @` 권장
  - 단가(2,)·판매량(2,5) = 요일별 매출(5,) — '행×열'이 매출 공식이 되는 이유
- linalg: `A.T`, `inv`, `det`, `eig`, `solve(A,b)`, `svd/qr`, `norm`, `matrix_rank`, `cond`
- 무작위: `rand`, `randint`, `normal(170,10)`, `binomial`, `poisson`. 확률: `math.factorial`, `np.prod`
- 구조화 배열: dtype 정의, `.view(np.recarray)`로 `x.y.mean()`. 파일: `np.save/load`(.npy), `savetxt/genfromtxt`

## PART 3 — 빅데이터와 Spark
- 3V (Volume·Velocity·Variety), 구조적(필드·SQL) vs 비구조적(입소문 텍스트)
- 빅데이터 vs 통계학: 통찰·예측 / 가설검정, 전체 / 표본, 분산처리 필수 / 불필요, Hadoop·Spark / SAS·SPSS
- 과학적 절차: 의문 제기 → 데이터 수집 → 모델링·분석 → 추론. business value에 답할 수 있어야
- 라이프사이클 6단계: 문제정의 → 수집(크롤링·API·Kafka) → 정제(맵리듀스) → 저장(csv·MongoDB·HDFS) → 분석(knn·decision tree) → 보고(d3.js·Tableau). OLTP vs OLAP, ETL
- Hadoop 3계층: MapReduce(앱) / YARN(자원관리) / HDFS(스토리지). 수집·저장·배치
- Spark: 인메모리 분석 엔진, 자체 파일시스템 없음, 다중 언어(Scala·Java·Python·R), MLlib 내장
  - Spark Core 위에 SQL·Streaming·MLlib·GraphX. 2009 UC Berkeley → 2014 1.0 → 2020 3.0 (Py2 중단)
- **클러스터 아키텍처**: Driver(main, 계획) → Cluster Manager(자원 배분: local·YARN·Mesos·K8s) → Worker/Executor/Task(병렬 실행) → 결과 반환 → `spark.stop()` → 자원 회수
- 실행: batch(`spark-submit`) / interactive(REPL, Jupyter). pip 설치(로컬 학습용) vs 완전 설치(클러스터, SPARK_HOME·JAVA_HOME 필요)
- SparkSession:
  ```python
  import pyspark
  spark = pyspark.sql.SparkSession.builder.master("local").appName("myApp").config(conf=myConf).getOrCreate()
  spark.version; spark.stop()
  ```
- pyspark 위치 = sys.path 규칙으로 찾기. site-packages/pyspark = SPARK_HOME (bin, python/lib의 pyspark.zip·py4j, jars). 완전설치면 `findspark.init()` 또는 `sys.path.insert()`
- 멀티 버전 문제: `os.environ['PYSPARK_PYTHON'] = sys.executable`
- SparkConf: `spark.conf.get('spark.master')`, `spark.sparkContext.getConf().getAll()`, `._conf.set('spark.executor.memory','8g')`. 로그 수준, `spark.jars` / `spark.jars.packages`(maven 좌표)
